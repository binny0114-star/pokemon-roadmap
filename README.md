# 포케루트 (Poké Route)

1–5세대 본가 21개 버전에서 좋아하는 포켓몬 1–6마리 또는 단일 타입 챌린지를 고르면, 파티와 그 파티 전용 스토리 로드맵을 결정론적으로 만드는 오프라인 우선 한국어 웹 앱입니다.

## 지원 게임

| 세대 | 버전 |
| --- | --- |
| 1세대 | 레드, 그린, 블루, 피카츄(옐로) |
| 2세대 | 금, 은, 크리스탈 |
| 3세대 | 루비, 사파이어, 에메랄드, 파이어레드, 리프그린 |
| 4세대 | 디아루가(다이아몬드), 펄기아(펄), 기라티나(플래티넘), 하트골드, 소울실버 |
| 5세대 | 블랙, 화이트, 블랙 2, 화이트 2 |

은·크리스탈·사파이어·에메랄드는 기존 검수 파티를 한 번에 필수 멤버로 불러오는 단축 버튼도 제공합니다.

## 실행과 검증

```bash
npm install
npm run dev
npm run lint
npm test
npm run validate:data
npm run build
```

정적 원본 스냅샷을 다시 생성할 때만 인터넷이 필요합니다.

```bash
npm run generate:data
```

생성된 앱 자체는 외부 API, 계정, 서버, 자격 증명을 사용하지 않습니다.

## 생성기 동작

1. 버전을 선택합니다.
2. 밸런스 파티 또는 해당 세대의 단일 타입 챌린지를 선택합니다.
3. 검색 가능한 전국도감에서 필수 멤버 1–6마리를 선택합니다. 단일 타입 모드의 첫 선택은 데이터 수정으로 교체할 Lv.5 스타팅입니다.
4. 무교환, 필드기 편의, 전설, 엔딩 후 입수 허용을 설정합니다.
5. 엔진이 스토리 합류 시점, 남은 보스 상성, 공격 타입 다양성, 공통 약점, 종족값 역할, 버전별 필드기 기여를 점수화합니다.
6. 점수 동률은 전국도감 번호로 결정하므로 같은 입력은 항상 같은 파티를 만듭니다.

필수 멤버는 자동으로 제거되지 않습니다. 추천 멤버는 잠그거나 상위 대안으로 교체할 수 있으며, 잠금 외 슬롯만 다른 결정론 대안으로 재생성할 수 있습니다. 스타터·화석 상호 배타, 6마리 초과, 통신진화, 엔딩 후 입수, 세대 미등장, 이벤트/타 버전 교환 전용은 생성 전에 명시적으로 차단합니다.

단일 타입 챌린지는 복합 타입을 포함해 모든 전투 멤버가 선택 타입을 공유하도록 후보·대안·임시 보스 대응을 제한합니다. 첫 번째 필수 포켓몬은 사용자가 게임 데이터를 수정해 원래 스타터 대신 받는 Lv.5 포켓몬으로 취급합니다. 따라서 해당 세대에 존재하고 선택 타입을 공유한다면 원래 버전의 조우·교환진화·엔딩 후 제한을 받지 않습니다. 나머지 멤버는 실제 버전별 입수 조건을 그대로 지킵니다. 원래 스타터 이벤트는 교체되므로 다른 원래 스타터는 추가 추천하지 않습니다.

희소 타입에 개조 스타팅과 실제 획득 가능한 서로 다른 진화 계열을 합쳐 6개 미만이면 가능한 1–5마리만 구성하고 부족 수를 경고합니다. 진행 필드기를 맡을 타입 밖 임시 요원이 필요하면 이동용으로만 사용하고 전투에는 참가시키지 않는 규칙을 안내합니다.

## 동적 로드맵

8개 스토리 패밀리(`RGBY`, `GSC`, `RSE`, `FRLG`, `DPPt`, `HGSS`, `BW`, `B2W2`)가 공통 연대기와 보스 데이터를 공유하고 버전 차이를 덮어씁니다. 생성된 파티마다 다음 항목을 다시 합성합니다.

- 포획 위치·레벨·합류 장과 데이터 품질
- 단계별 진화 시점과 통신교환 경고
- 버전별 실제 자력기·TM/HM·기술가르침 호환과 당시의 기술 타입·위력
- 해당 장까지 합류·진화·습득 가능한 멤버만 사용한 보스 대응
- 늦게 합류하는 필수 멤버의 임시 카운터
- 단일 타입 규칙과 해당 타입 안에서 가능한 임시 카운터
- 1–4세대 1회용 TM 충돌 가능성
- 해당 세대/버전에 존재하는 HM·필드기만 사용한 배치표

진행률 키는 `버전 + 생성 플랜 ID`로 분리되어 파티 변경이 다른 진행 기록을 덮어쓰지 않습니다.

## 로컬 트레이너 계정

헤더의 로그인 메뉴에서 닉네임과 숫자 PIN으로 이 브라우저 전용 계정을 만들 수 있습니다. PIN은 PBKDF2-SHA-256으로 해시해 저장하며, 빌더 상태·현재 플랜·체크리스트 진행률·클리어 목록은 계정별로 분리됩니다. 로드맵의 모든 파티 액션을 체크하면 사용 버전, 챌린지 유형, 파티와 완료 날짜가 클리어 목록에 기록됩니다.

계정 데이터는 오프라인 우선 원칙에 따라 외부 서버로 전송되지 않습니다. 따라서 같은 브라우저에서는 새로고침 후 복원되지만 다른 기기나 브라우저와 동기화되지 않으며, 브라우저 저장 데이터를 삭제하면 함께 사라집니다. 첫 계정 생성 시 기존 게스트 플랜과 진행률은 자동으로 가져옵니다.

## 데이터 구조

- `src/generated/species.json`: 전국도감 #001–649, 한국어 이름, 현재 타입/종족값, 진화 조건, 지원 버전 조우 스냅샷
- `src/generated/learnsets.json`: 12개 지원 버전 그룹, 649종의 자력기·TM/HM·기술가르침 호환과 기술 변경 이력
- `src/planner/catalog.ts`: 버전별 획득 가능성, 조우 장, 엔딩 전/후, 교환·스타터·화석 판정
- `src/planner/games.ts`: 21개 버전과 8개 공유 스토리 패밀리, 보스, 필드기
- `src/planner/engine.ts`: 세대 타입 보정, 제약 검증, 결정론 점수, 잠금·대안, 커버리지
- `src/planner/roadmap.ts`: 선택 파티별 포획·진화·기술·보스 액션 합성
- `src/planner/storage.ts`: 빌더와 플랜별 진행률 저장
- `src/data`: 기존 4개 검수 프리셋
- `scripts/generate-catalog.mjs`: 개발 시 PokéAPI GraphQL 데이터를 정규화하는 스냅샷 생성기
- `scripts/generate-learnsets.mjs`: PokéAPI CSV를 버전별 합법 기술표로 정규화하는 생성기

## 출처와 한계

정적 종·진화·조우 스냅샷은 [PokéAPI](https://pokeapi.co/) GraphQL 데이터에서 생성했습니다. 스토리·보스·HM 차이는 [pret/pokered](https://github.com/pret/pokered), [pret/pokecrystal](https://github.com/pret/pokecrystal), [pret/pokeemerald](https://github.com/pret/pokeemerald), [pret/pokeplatinum](https://github.com/pret/pokeplatinum), [pret/pokeheartgold](https://github.com/pret/pokeheartgold), [pret/pokeblack](https://github.com/pret/pokeblack), Bulbapedia와 Serebii의 버전별 자료를 교차 참고했습니다.

기술 스냅샷은 지원 버전별 실제 자력기 레벨, TM/HM 번호, 기술가르침 호환과 기술 변경 이력을 포함합니다. 따라서 구세대 미등장 기술이나 해당 포켓몬이 배울 수 없는 기술은 추천하지 않으며, 1–3세대 타입 기반 물리/특수 분류와 당시의 기술 타입·위력을 적용합니다. 자력기는 정확한 레벨에 배치하지만 일반 TM과 기술가르침의 지도상 획득 위치는 아직 별도 스냅샷이 없어 보수적인 스토리 장에 `시점 추론`으로 표시합니다. 위치 토큰을 한국어로 확정하지 못한 경우 영문 원본 위치를 숨기지 않고 그대로 노출합니다. 그린은 별도 PokéAPI 버전이 없어 계보가 가까운 Blue 조우 스냅샷을 사용하며 이를 화면에 표시합니다.
